## When to use this

Set the shelter's state once, when the shelter starts using the app, and
again only if the shelter moves. A transfer in or out is counted as in
state, out of state or outside the US by comparing the partner's state and
country with this one.

A partner's own state and country are set on the partner. See "Add or edit a
partner" in **Help**.

## Steps

1. In the sidebar, open **Settings**, then the **Shelter Details** card. The
   page shows the shelter's **State**, or **Not set**.
2. Click **Edit shelter details**.
3. Pick the **State**. Only the 50 US states are offered.
4. Click **Save Shelter Details**.

You should see "Shelter details saved." The box closes and the page shows
the state you picked, for example "New York".

If you close the box with a change not saved, it asks "Discard unsaved
shelter details?". Click **Cancel** to go back, or **Discard** to lose the
change.

Once set, the state can be changed but not cleared.

## If something goes wrong

- **"Select the state the shelter is in."** No state is picked. Pick one.
- **"Database Error: Failed to save the shelter details."** Nothing was
  saved. Try again. If it keeps happening, tell an admin.
- **Access Denied.** Only an admin can change the shelter's details.
