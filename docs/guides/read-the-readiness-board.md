## When to use this

The **Readiness Board** lists every animal that is still on the shelter's books
and not yet fully ready for adoption, grouped by what is holding it back. Use
it to see the whole shelter at once and to pick the next thing to do.

To see one animal's own list, open it and read the **Readiness** box on its
**Activity** tab instead. To see who is in which kennel, use the Housing
Board.

The board only shows what is outstanding. What you can do about it depends on
your account: some people get a link that opens a form, others a link that opens
the record to read.

## Steps

1. In the sidebar, open **Readiness Board**.
2. Read the line next to the filters, for example "62 of 62 animals not ready
   · 0 ready". It counts the animals that match the filters, not only the
   group you are looking at.
3. Read the tiles. There is one per kind of blocker, with how many animals have
   it. **Escalated findings**, **Needs vet review** and **Under care** are the
   urgent ones: they are tinted red, and their headings have a red icon. Click a
   tile to open only that group. A tile with a 0 is greyed out and doesn't
   open anything.
4. Scroll down to the groups, in the same order as the tiles. Each group has
   a short line saying what the blocker is and a table with the **Animal**, its
   **Location**, its **Stage**, how long it has been **Outstanding for** (with
   the date it started under it) and **What clears it**.
5. Within a group, the animal that has waited longest is first.
6. Click the link in **What clears it** to go to the place where it is fixed.
   Click the animal's name to open its record.

Each group shows its first five animals. If there are more, click **Show all**
(for example **Show all 61**) under the table to see every animal with that
blocker, ten to a page. Use **Previous** and **Next** to turn pages. Click
**All groups** at the top to go back.

## What each blocker means

| Group | It means | What clears it |
|---|---|---|
| **Escalated findings** | The latest check of one kind was recorded with the **Escalate** signal, for example "Cat Test of Nov 12, 2026". | Someone records a newer check of the same kind that isn't escalated. It can be any check, not only the required ones. |
| **Needs vet review** | The latest exam of this stay asked for a vet's review. | A later exam with another result. |
| **Under care** | The animal has an open care episode, for example "Hospitalised in house since Nov 18, 2026". | Closing the care episode. |
| **Unsupported characteristics** | A trait on the profile that something now speaks against, for example "Good with other dogs — contradicted by a live finding". The other reasons are "cites a deleted assessment", "its assessment no longer supports it", "its condition was resolved" and "cites a voided condition". | Fixing what the trait rests on, or taking the trait off the animal. Review characteristics opens the animal's traits. |
| **Missing assessments** | A check the shelter requires has nothing on file for this stay. The row names it, for example "Cat Test". | Recording that check. |
| **No intake exam** | There is no intake exam on the medical record for this stay. | Recording an intake exam dated on or after the day the animal came in. An exam from an earlier stay doesn't count. |
| **Not spayed or neutered** | The record shows no spay or neuter, and no exemption is in force. | Recording the surgery, or an exemption. |
| **No photo** | Adopters have nothing to see yet. | Adding a photo to the profile. |

An animal appears once in each group it belongs to, so it can be in several.
**Outstanding for** counts from when that blocker began: the day of the
check, exam or episode, or the day the animal came in. A trait counts from
the later of when it was added and when what it rests on changed. An animal that
isn't spayed or neutered counts from the day after a lapsed exemption, if
that is later than the day it came in.

### Which checks are required

Only checks done at intake, or to prepare an animal for adoption, are
required, and only the ones made for the animal's species. A check meant for
dogs is not asked of a cat. Checks made for later care, such as **Daily
Rounds**, are not required, and **Handling Sensitivity** isn't either. Any
version of a required check counts once it is on file.

## Narrow the board

1. Click **Species**, **Location** or **Stage** and tick one or more values.
   **Location** lists each area and also **In foster** and **Unplaced**, if any
   animal is there. **Stage** offers **Draft**, **Published** and **Pending
   adoption**. Each list offers only values that some animal on the board has
   now. Animals that have left the shelter are not on the board.
2. Several values in one filter match any of them. Different filters must
   all match.
3. A **Reset** button appears once a filter is set. Click it to clear the
   filters. If you had opened one group with **Show all**, it stays open.

The filters stay in the address, and **Show all** keeps them, so you can
send a filtered view to a colleague.

## Fix links

The link in **What clears it** depends on what your account may do.

| Blocker | If you can do it | If you can only read |
|---|---|---|
| **Missing assessments** | **Record Cat Test** (the name of the check): opens the form with that check chosen | **View assessments** |
| **No intake exam** | **Record intake exam** | **View medical record** |
| **Not spayed or neutered** | **Record spay/neuter** | **View medical record** |
| **No photo** | **Add a photo** | **View photos** |
| **Escalated findings** | **Review the Cat Test** (the name of the check): opens that check | same |
| **Needs vet review** | **Review the exam**: opens the animal's exams | same |
| **Under care** | **View care episode** | same |
| **Unsupported characteristics** | **Review characteristics** | same |

Volunteers get the read-only links. If you can't record something, the link
still takes you to the record, so you can see what is there and ask a staff
member to add it. The guides on each task are listed at the end of this page.

## If something goes wrong

- **"Access Denied".** Your account can't read the board. Ask an admin.
- **"Every animal that matches these filters is ready."** Nothing is
  outstanding for the animals you filtered to.
- **"No animals match these filters."** No animal has that species, location
  or stage. This also shows for an old or hand-edited link with a value that
  no longer exists. Click **Reset**.
- **"Nothing here matches these filters."** You opened a group, or a page of
  it, that is empty: another person may have fixed the last animal. Click
  **All groups**.
- **An unknown group in the address** shows all groups.
- **A page number below 1, or not a whole number,** shows the first page. A
  page past the last one shows **"Nothing here matches these filters."**
- **A blocker you fixed is still listed.** Reload the page. The board shows
  the record as it is when the page loads.
