## When to use this

Characteristics are traits from the shelter's list, grouped as **Behavior**,
**Medical**, **Environment**, **Administrative** and **Other**. They describe the animal
to adopters and to staff, for example "Good with kids" or "Needs a quiet
home".

Some characteristics come from a behavior assessment instead: see
[Record a behavior assessment](./record-a-behavior-assessment.md). The list
of traits to pick from is kept by an admin in **Settings**.

## Steps

1. Open the animal, then the **Characteristics** tab.
2. Click **Edit**. (On an animal with none yet, you can click **Add
   Characteristics** instead.) The box **Edit Characteristics** opens, with
   the animal's traits under **Selected Characteristics**.
3. To add a trait, click **Add a characteristic...**, type part of its name,
   and pick it. Traits the animal already has aren't listed.
4. To remove a trait, click the **x** beside its name.
5. Click **Save Changes**.

You should see "Characteristics updated successfully." The tab lists each
trait under its group, with who added it and when, for example "Added by
Olivia Chen on November 16, 2026". A trait added from an assessment also
names it: "— from the Dog-to-Dog Introduction assessment of November 16,
2026".

To close the box without saving, click **Cancel**. If you changed something,
it asks "Discard unsaved changes?" first.

## When an assessment contradicts a trait

If a behavior assessment found something that argues against a trait, the
trait shows a warning under it, for example "Contradicted by
“Recommendation”: Not cat-safe on the Cat Test of November 7, 2026."
Click the assessment's name to read it. The trait isn't removed for you:
decide whether it still fits, and remove it if not.

## If something goes wrong

- **The trait you need isn't in the list.** Only traits on the shelter's
  list can be picked. Ask an admin to add it.
- **"One or more characteristics are no longer available and cannot be
  assigned."** An admin deleted a trait while you had the box open. Reload
  the page and pick again.
- **"Failed to update characteristics due to a server error."** Nothing was
  saved. Try again; if it keeps happening, tell an admin.
