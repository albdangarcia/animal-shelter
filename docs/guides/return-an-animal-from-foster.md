## When to use this

Use this when an animal comes back from a foster to the shelter, and is
staying. If the animal is leaving the shelter instead (adopted, transferred,
returned to its owner or dead), don't return it: record an outcome. See
"Record an adoption, transfer out, return to owner or other outcome" in
**Help**. The outcome ends the placement itself. For a foster adopting a
**Foster To Adopt** animal, see
[Turn a foster into an adoption](./turn-a-foster-into-an-adoption.md).

## Steps

1. Open the animal and click **Return from Foster** in the banner at the top. You
   can also click **Return** under **Current Placements** on the foster's
   **Fostering** tab.
2. Under **Return Reason**, pick one. See the next section.
3. Under **Location**, pick where the animal goes, then pick a **Unit**. A unit
   reads, for example, "A-1 · 2/1 (full)": its animals out of its capacity. If
   the animal's old unit still exists, its location is already picked.
4. Add any **Notes**.
5. Click **Return From Foster**.

You should see "Animal returned from foster." and the animal's page opens. The
foster banner is gone, **Location** shows the unit, and **Activity** shows
"returned this animal from foster" with your notes. On the foster's
**Fostering** tab, the placement moves to **Placement History** with the day it
ended and the reason. The foster sees it under **Past fosters**.

A **Foster To Adopt** animal's listing goes back to what it was before the
placement.

The reason is a label for the history. It changes nothing else. A unit marked
"(full)" can still be picked, so check that it has room.

## Return reasons

The app offers **Returned To Shelter**, **Transferred**, **Medical** and
**Other**. It doesn't define them. Every one puts the animal into the unit
you pick, so pick the closest and say more in **Notes**. If the animal is
leaving the shelter, don't use **Transferred**: record an outcome instead.

Two reasons you won't see here are set by other steps. **Adopted By Foster** is
set when you turn a foster into an adoption. **Ended: …** (for example "Ended:
transfer out") is what the foster's history shows when an outcome ended the
placement. A return never sets either.

## If something goes wrong

- **"A return reason is required."** Pick a **Return Reason**.
- **"Pick a unit."** under **Unit.** Pick a location and a unit.
- **Placement Already Ended** (page), or **"This foster placement has already
  ended."** Someone already returned the animal. Open its page to see where
  it is.
- **"That unit is no longer available. Please choose a different unit."** The
  unit was deleted. Pick another.
- **"This animal has already left the shelter, so it can't be returned from
  foster."** An outcome was recorded. See "Take back an animal that left" in
  **Help**.
- **"Foster placement not found."** Go back to **Fosters**.
- **"Database Error: Failed to return animal from foster."** Nothing was
  saved. Try again. If it keeps happening, tell an admin.
- **Access Denied.** Your account can't return animals. Ask a staff member
  who manages fosters.
