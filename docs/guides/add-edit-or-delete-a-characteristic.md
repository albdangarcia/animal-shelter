## When to use this

Characteristics are the traits staff tick on an animal's **Characteristics**
tab, such as "Good with cats" or "Deaf". Each one sits in a category:
**Behavior**, **Medical**, **Environment**, **Administrative** or **Other**.
Use this guide to add one to the list, change one, or take one out of use.

To tick a trait on one animal, open the animal's **Characteristics** tab
instead.

## Add a characteristic

1. In the sidebar, open **Settings**, then the **Characteristics** card. The
   characteristics are listed by category.
2. Click **Add Characteristic**.
3. Type the **Name**, for example "Good with cats".
4. Pick the **Category**. It starts on **Behavior**.
5. Click **Create Characteristic**.

You should see "Characteristic created successfully." The characteristic
appears under its category, and staff can tick it on any animal's
**Characteristics** tab.

## Edit a characteristic

1. Click the **…** button beside the characteristic, then **Edit**.
2. Change the **Name** or the **Category**.
3. Click **Update Characteristic**.

You should see "Characteristic updated successfully." A new name shows on
every animal that has the characteristic. A new category moves it under that
heading.

## Delete a characteristic, or bring it back

Delete a characteristic staff should stop using.

1. Click the **…** button beside the characteristic, then **Delete**. There is
   no confirmation, so check the name first.

You should see "Characteristic deleted successfully." with an **Undo**
button. The characteristic stays in the list, faded, marked **Deleted**. It
no longer shows on any animal's **Characteristics** tab, including animals
that had it.

To bring it back, click **Undo** on the message, or click **…**, then
**Restore**. You should see "Characteristic restored successfully." Animals
that had it show it again.

## If something goes wrong

- **"Name is required."** Type a name.
- **"A characteristic with that name already exists."** Each name can be used
  once, in any category. Pick another name, or edit the one that has it. If
  that one is marked **Deleted**, restore it instead.
- **"Good with cats is proposed by the Cat Test assessment template, so it
  can't be deleted."** (with the characteristic's and template's names) An
  assessment template suggests this characteristic from its findings, so it
  must stay. You can still rename it.
