## When to use this

Use this when the foster of a **Foster To Adopt** placement decides to adopt
the animal. One step records the adoption and ends the placement. It works
only for that placement type. For any other placement, record the adoption
as an outcome: see "Record an adoption, transfer out, return to owner or other
outcome" in **Help**. If the foster instead brings the animal back, see
[Return an animal from foster](./return-an-animal-from-foster.md).

Before you start, the foster should have an adoption application for this
animal and you should have approved it. Approving needs the animal to be
**Published**, and a **Foster To Adopt** placement makes it **Pending Adoption**,
so do it before placing the animal: see
[Place an animal in foster](./place-an-animal-in-foster.md#the-four-placement-types).

## Steps

1. Open the animal and click **Convert to Adoption** in the banner at the top. You
   can also click it under **Current Placements** on the foster's **Fostering**
   tab. If you click **Create Outcome** on the foster's approved application
   instead, the page **Convert the Foster Placement** offers the same button.
2. If the foster has an approved adoption application for this animal, the
   page shows **Link** *name*'s **approved application**. When there is exactly
   one, it is already picked. Leave it picked. Pick **None** only to link
   nothing. With two or more, nothing is picked and **None** shows as chosen, so
   pick the right one. If the foster has no approved application, the choice
   isn't shown and nothing is linked.
3. Click **Convert to Adoption**.
4. A box says "Confirm adoption" and "*Animal* will be marked as adopted by
   *name*. This action is final." Click **Confirm & Convert**.

You should see "Foster placement converted to adoption." and the animal's
page opens. Its card reads **Archived**, and the button now reads **Create
Re-Intake**.

## What it records

- **An adoption outcome**, dated today. There is no date or notes box. It
  appears on **Outcomes** with your name. The adopter shown is the person on
  the linked application, which has to be the foster's own.
- **The animal is archived**, like any adoption: it leaves the listings.
- **The placement ends**, today, with the reason **Adopted By Foster**. It is
  linked to the outcome and to the application.
- **The linked application reads Adopted.** Every other application still open
  on the animal reads **Closed**. None is rejected. "Adopted" and "Closed" are
  explained in the adoption application status glossary in **Help**.
- **Activity** shows "processed an outcome" and "returned this animal from
  foster".

Without a linked application, no application reads **Adopted**, the outcome
shows no adopter (**Recipient** reads N/A on **Outcomes**), and every open
application, the foster's included, reads **Closed**. Link the application
whenever you can.

The foster's **My Foster Animals** page moves the animal to **Past fosters**.
They aren't told otherwise.

## How it differs from recording an adoption by hand

Recording an adoption as an outcome asks you for the day and notes, and starts from
the adopter's approved application. This one takes today as the day, has no
notes, and takes the adopter only from the application you link. The results
are otherwise the same outcome, and the same changes to applications.

It can't be undone from this page. If it was a mistake, an admin can reverse the
outcome: see "Reverse an outcome recorded by mistake" in **Help**. That
reopens the placement.

## If something goes wrong

- **Not a Foster-to-Adopt Placement** (page). Only foster-to-adopt placements
  can be converted. Use the outcome steps for other placements.
- **Placement Already Ended** (page), or **"This foster placement has already
  ended."** Someone returned the animal or recorded an outcome. Open the animal.
- **"That adoption application does not belong to this animal."** or **"That
  adoption application does not belong to this foster."** Reload the page and
  pick again. Only the foster's own application for this animal is offered.
- **"Cannot convert: the linked adoption application has not been approved."**
  The application changed. Review it, or pick **None**.
- **"This application already has an adoption recorded against it."** The
  adoption is already on **Outcomes**.
- **"This animal has already been processed for an outcome."** Someone recorded
  an outcome first. Find it on **Outcomes**.
- **"Database Error: Failed to convert foster placement."** Nothing was saved.
  Try again. If it keeps happening, tell an admin.
- **Access Denied.** Your account can't manage fosters. Ask a staff member
  who can.
